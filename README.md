# Python File & Folder Manager

A simple command-line File and Folder Manager built with Python.

## Features

* Create, read, update, and delete files
* Rename files
* Create and view folders
* Rename and delete folders
* Create files inside folders
* Handles invalid input and existing file/folder names

## Concepts Used

* Python Functions
* File Handling
* `pathlib`
* `os`
* `try-except`
* Loops and Conditional Statements

## How to Run

```bash
python file_manager.py
```

Replace `file_manager.py` with your actual Python file name if it is different.
